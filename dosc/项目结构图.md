## 核心类说明

| 类名 | 职责 | 位置 |
|------|------|------|
| **SimpleController** | 核心控制器，整合 ADB 和 Vision | `include/SimpleController.hpp` |
| **ADBClient** | ADB Socket 通信客户端 | `include/adb/ADBClient.hpp` |
| **OcrPack** | OCR 引擎封装 (检测+识别) | `include/vision/ocr_pack.h` |
| **TaskExecutor** | 任务执行器 (std::visit) | `include/task/TaskExecutor.hpp` |
| **TaskLoader** | JSON 任务解析器 | `include/task/TaskLoader.hpp` |
| **TaskConfig** | 任务配置 (variant 类型) | `include/task/TaskConfig.hpp` |

## 依赖库

| **OpenCV** | 图像处理 |

## 执行流程简述

```
1. 加载任务 JSON 文件
       │
       ▼
2. TaskLoader 解析为 TaskConfig
       │
       ▼
3. TaskExecutor 遍历 steps
       │
       ▼
4. std::visit 分发执行
       │
       ├──► BasicStep  → click/swipe/wait
       ├──► VisionStep → screenshot/ocr/template
       └──► SystemStep → shell/start_app
              │
              ▼
5. SimpleController 调用 ADB/Vision 执行
```

## JSON 任务示例

```json
{
  "name": "start_arknights",
  "description": "启动明日方舟游戏",
  "loop": false,
  "steps": [
    { "action": "shell", "shell_cmd": "am start -n com.hypergryph.arknights/..." },
    { "action": "wait", "duration": 7000 },
    { "action": "screenshot", "save_name": "screen.png" },
    { "action": "ocr_click", "save_name": "screen.png", "text": "开始唤醒" }
  ]
}
```
